# 🛒 Tutorial Buat POS (Point of Sales)

Aplikasi POS (Point of Sales) adalah aplikasi yang digunakan untuk mengelola transaksi pada sebuah toko atau oleh kasir. Aplikasi ini dibuat menggunakan **Laravel v8.\*** dan membutuhkan minimal **PHP v7.4**. 

> ⚠️ **Catatan:** Apabila pada saat proses instalasi atau penggunaan terdapat error atau bug, kemungkinan besar disebabkan oleh versi PHP yang tidak sesuai (tidak support).

## ✨ Fitur Utama

- **Manajemen Kategori Produk**
- **Manajemen Produk** (Multiple Delete, Cetak Barcode)
- **Manajemen Member / Anggota** (Cetak Kartu Member)
- **Manajemen Supplier**
- **Transaksi Pengeluaran, Pembelian, dan Penjualan**
- **Laporan Pendapatan / Laba & Rugi** (Bulanan, Harian, Custom Tanggal)
- **Custom Tipe Nota** (Nota Besar, Nota Kecil / Thermal Nota)
- **Manajemen User dan Profil** (Administrator, Kasir)
- **Pengaturan Toko** (Identitas, Upload Desain Kartu Member, Setting Diskon Member)
- **Grafik ChartJS** pada Dashboard
